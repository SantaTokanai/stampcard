管理者ページ

グッズ交換・曲リクエスト・ユーザーの状況を確認できます
やりたいことの見出しをタップすると、手順が開きます。
🔰 まず知っておく言葉

画像：アップロードした絵のファイルです。アップしただけでは、サイトのどこにも表示されません。

スタンプ：スタンプカード（台紙）の上に押される絵です。「どの合言葉で、台紙のどこに、どの大きさで出すか」を決めたものをスタンプ設定と呼びます。

合言葉：ユーザーが入力するとスタンプが押されるキーワードです。スタンプ設定の「ID」がそのまま合言葉になります。

アイコン：ユーザーのページの「アイコン置き場」に並ぶ、プレゼント用の画像です。スタンプとは別のものです。

🆕 新しいスタンプ（合言葉）を追加したい
  1. 「🖼 画像・スタンプ」タブ →「画像」で、スタンプの画像をアップロード
  2. 「📍 スタンプ配置」→「＋ 新しいスタンプ設定を作る」
  3. 「合言葉（ID）」を入力（例：souki_07）
  4. 「画像」欄に、アップした画像を入力して選ぶ
  5. 台紙をタップして位置を決め、スライダーで大きさを決める
  6. 「保存」

→ ユーザーがその合言葉を入力すると、台紙にスタンプが押されます。

ユーザーの名前や項目名が、合言葉と違う場合は、「実際に保存する項目名」に入力します（通常は空欄でOK）。

📍 スタンプの位置や大きさを直したい
  1. 「🖼 画像・スタンプ」→「📍 スタンプ配置」
  2. 一覧から直したいスタンプの「編集」
  3. 台紙をタップ（またはドラッグ）して位置を変える。大きさはスライダー
  4. 「保存」

保存すると、ユーザーの画面に反映されます（ユーザーがページを開き直すと変わります）。

🎁 ユーザーにアイコンをプレゼントしたい
  1. 「🖼 画像・スタンプ」→「🖼 画像」で、アイコン画像をアップロード（保存先フォルダは、そのユーザー用のフォルダ名。例：akkii）
  2. 「🎁 ユーザーのアイコン」を開く
  3. ユーザー名を入力（または候補から選ぶ）→「表示する」
  4. 「アイコンを追加」欄に、アップした画像を入力して選ぶ →「追加する」

→ そのユーザーの「アイコン置き場」に表示されます。

↩️ プレゼントしたアイコンを外したい

「🎁 ユーザーのアイコン」でユーザーを表示し、外したい画像の「外す」を押します。画像そのものは消えません（他のユーザーにも使えます）。

🗑 間違えてアップした画像を消したい

「🖼 画像」の一覧で、その画像の「削除」を押します。元に戻せません。ユーザーに贈っている画像は、先に「外す」を行ってください。スタンプ設定で使っている画像を消そうとすると、確認が出ます。

✋ ユーザーにスタンプを手動で押したことにしたい
  1. 「👤 ユーザー」タブで、そのユーザーの名前をタップ
  2. 下の入力欄に、スタンプの項目名（スタンプ設定の「合言葉（ID）」）を入力
  3. 「true にする」を押す

項目名がわからないときは、「📍 スタンプ配置」の一覧で確認できます。

📦 グッズ交換：申し込み内容の確認と配送URLの登録
  1. 「🎁 グッズ交換」タブで、交換会を選ぶ
  2. 申し込み一覧に、ユーザーごとの内容と消費ptが出ます
  3. 配送URLを貼り付けて「保存」すると、ユーザー側に「配送用URLはこちら」が表示されます
🎵 曲リクエストを「済み」にしたい

「🎵 曲リクエスト」タブで、歌い終わった曲の「歌い終わったら済みにする」を押します。済みにすると、そのユーザーは次のリクエストができるようになります。

⚠️ 注意
  • 画像のファイル名・フォルダ名は、半角英数字と「_」「-」のみ。1枚5MBまで。
  • 同じ名前の画像をアップすると、通常は「既にあります」と止まります。入れ替えたいときは「同じ名前の画像があれば上書きする」にチェックします（ユーザー側は、ページを開き直すと変わります）。
  • スタンプ設定を削除しても、ユーザーが「押した」記録は消えません（台紙に出なくなるだけです）。
  • 困ったときは、画面の文言をそのまま控えて相談してください。
